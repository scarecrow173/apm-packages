# token-compression

`token-compression` は言語モデルとのやり取りにおけるトークン使用量を最適化するための戦略とツールを提供します。

このパッケージは意図的に依存関係を優先する構成です。独自のスキル、エージェント、プロンプト、MCP サーバーは含めず、トークン最適化と圧縮技術に焦点を当てたパッケージを集約します。

## カバー範囲

このパッケージはプロンプト圧縮、コンテキストエンジニアリング、トークンバジェット管理、AI支援開発における効率的なメッセージ構造化をカバーしています。
