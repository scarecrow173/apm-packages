# 関連エージェント

## エージェント概要

`token-compression` パッケージは、トークン最適化と効率的なプロンプトエンジニアリングを専門とするエージェントおよびサブエージェントと連携します：

### トークン最適化エージェント
- **目的:** トークン使用パターンを分析し最適化する
- **スキル:** トークンカウント、バジェット配分、圧縮戦略
- **用途:** コンテキストオーバーヘッドの削減、トークンバジェット管理

### コンテキストエンジニアリングエージェント
- **目的:** コンテキストを効率的に構造化し圧縮する
- **スキル:** コンテキスト選択、情報密度最適化
- **用途:** 集中したプロンプト作成、冗長性最小化

### プロンプト圧縮エージェント
- **目的:** セマンティック意味を保持しながらプロンプトを圧縮する
- **スキル:** プロンプト短縮、ロスレス圧縮技術
- **用途:** 品質を落とさずに入力トークン数を削減

## 統合ポイント

これらのエージェントは以下と組み合わせることができます：
- `agentic-eval` — 圧縮効果の測定用
- `incremental-implementation` — 段階的なトークン最適化改善用
- `brainstorming` — 圧縮戦略の探索用

信頼できる依存関係リストについては [apm.yml](./apm.yml) を参照してください。
