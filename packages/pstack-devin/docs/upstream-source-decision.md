# Decision: upstream pstack source of truth and distribution path

Status: accepted (verified against APM 0.33.0 — see `verification-apm-0.33.0.md`)
Date: 2026-11-16 · Issue: `#212`

## Context

`harness/pstack/claude-code` in `cursor/plugins` @`bf0c7cd8` is 546 files and
is classified by APM 0.33.0 as `package_type: agent_plugin` (Agent Plugins
v1.0.0, from `plugin.json` / `.claude-plugin/plugin.json`).

## Verified facts driving the decision

1. A virtual-subdirectory dependency resolves and pins correctly
   (`resolved_commit` = pinned SHA; `content_hash` attested).
2. `agent_plugin` packages install natively only for the `copilot` target;
   any other selected target fails the whole install transaction.
3. Under `copilot`, APM deploys zero tree files. It registers the plugin
   with Copilot's native mechanism (`.github/copilot/settings.local.json`:
   `enabledPlugins: pstack@apm`, `extraKnownMarketplaces` -> `apm_modules`).
   The lockfile records `deployments: []`.
4. `apm pack` bundles exclusively lockfile-attested `deployed_files`; with
   `deployments: []` an APM dependency can never ship the upstream tree.
5. Declaring the dependency under `dependencies:` would push the same
   copilot-only resolution onto every consumer and fail non-copilot
   installs outright.

## Decision

- The upstream tree is fetched build-side at a pinned commit by
  `scripts/pstack-devin` (issue `#213`), not delivered through an APM
  dependency. `upstream.yml` is the single authority for repo/path/commit.
- `apm.yml` carries the pin only as a `devDependencies` entry scoped
  `targets: [copilot]`: it produces `apm.lock.yaml` attestation
  (`resolved_commit`, `content_hash`, `is_dev`) with no consumer impact —
  devDeps are not installed transitively and are excluded from `apm pack`
  bundle contents.
- The upstream dep MUST NOT appear in `dependencies:`.
- Mismatch contract: `upstream.yml.upstream.commit`, the devDep `ref`, and
  `apm.lock.yaml.dependencies[0].resolved_commit` must be equal; the
  builder (issue `#213`) hard-fails on divergence and reports which side
  moved.
- `devin-plugin/` output is git-tracked under this package (generated by
  `#213`; published by `#217`).

## Alternatives rejected

- APM `dependencies:` on the virtual subdir — copilot-only `agent_plugin`,
  zero file deployment, breaks non-copilot consumer installs.
- Per-skill deps (`.../claude-code/skills/<name>`) — ships only skill-bundle
  primitives and loses playbooks, scripts, docs, images, and LICENSE
  (546 files reduced to a subset); also invents a second authority for what
  ships.
- Floating `#main` ref — violates the pinned-upstream rule.

## Consequences

- `scripts/pstack-devin` owns fetching (sparse checkout or equivalent at
  the pinned SHA), overlay, provenance, and determinism (issue `#213`).
- `apm.lock.yaml` here is generated by `apm install` only — never
  hand-edited.
- An upstream bump is one coordinated change: `upstream.yml` commit +
  `apm.yml` devDep `ref` + regenerate `apm.lock.yaml` + rebuild
  `devin-plugin/` (automation: issue `#219`).
- `apm audit` does not — per verification §3d — detect cache tampering;
  the rebuild-time recompute is the authoritative integrity gate regardless.
