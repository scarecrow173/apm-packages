# 調査監査

## 網羅性

- [ ] すべての必須観点に証拠がある。
- [ ] 高優先度タスクが完了している、または明示的に未解決として扱われている。
- [ ] 出力形式がユーザーの依頼に合っている。

## 証拠

- [ ] 重要な事実主張に情報源がある。
- [ ] 現在または変化し得る事実が、最近または公式の情報源で支えられている。
- [ ] 利用可能な場合は一次情報源を優先している。
- [ ] 読んでいない情報源を引用していない。

## 矛盾

- [ ] 矛盾する証拠を確認している。
- [ ] どの主張がより信頼できるかを情報源品質で説明している。
- [ ] 未解決の矛盾を開示している。

## 検索品質

- [ ] 公式 / 一次情報源検索を試みている。
- [ ] 批判的 / 否定的検索を試みている。
- [ ] 重複情報源を除去している。
- [ ] 高優先度ギャップに対して、少なくとも 1 回の追加検索を行っている。

## ユーザー意図との整合

- [ ] 前提が明示されている。
- [ ] ペルソナ / 意図モデルがユーザー制約を反映している。
- [ ] 確認判断は影響の大きい曖昧さに対してのみ使われている。
