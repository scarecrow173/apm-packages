# Flow Profile Specification

## Overview

Flow Profile (`*-profile.json`) is the **canonical artifact** that holds the
classification results, resolution results, and runtime guidance bound to a
specific flow.

It is generated by `sdp profile` and read by `sdp query`.

## File Formats

- Canonical: `.sdp/<adapter_id>/*-profile.json` (e.g.,
  `.sdp/briefing-flow-default/briefing-profile.json`,
  `.sdp/implementation-flow-default/implementation-flow-profile.json`)
- Derivative: `.sdp/<adapter_id>/*-profile.md` (for human review)

## JSON Schema (Outline)

```json
{
  "schema_version": "1.0",
  "profile_id": "briefing-flow-default",
  "generated_at": "2026-05-28T00:00:00Z",
  "validated_at": "2026-05-28T00:00:00Z",
  "adapter_id": "briefing-flow-default",
  "flow_stack": {
    "slots": [
      {
        "slot_id": "adr_authoring",
        "slot_type": "exclusive",
        "activation": "on_demand",
        "default": {
          "skill": "documentation-and-adrs",
          "reason": "ADR authoring tasks need architecture-focused output"
        }
      }
    ]
  },
  "classification": {
    "categories": [
      {
        "id": "architecture",
        "label": "Architecture",
        "skills": ["documentation-and-adrs"]
      }
    ],
    "unmatched_skills": []
  },
  "resolved_invocations": [
    {
      "source_skill": "implementation-flow",
      "slot": "adr_authoring",
      "capability": "adr_authoring",
      "resolved_skill": "documentation-and-adrs",
      "resolution_method": "slot_override",
      "reason": "ADR authoring tasks require architecture-focused output",
      "fallback": null
    }
  ],
  "runtime_guidance": [
    {
      "skill": "documentation-and-adrs",
      "context": "adr_authoring",
      "guidance": "Use when creating or updating architecture decision records",
      "priority_delta": 20,
      "prefer_when": ["adr_authoring", "design_decision"],
      "avoid_when": ["pure_copy_edit"]
    }
  ],
  "warnings": []
}
```

## Field Definitions

### Top-level

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `schema_version` | string | yes | Profile schema version |
| `profile_id` | string | yes | Profile identifier |
| `generated_at` | ISO 8601 | yes | Generation timestamp |
| `validated_at` | ISO 8601 | yes | Last validation timestamp |
| `adapter_id` | string | yes | ID of the adapter used |
| `flow_stack` | object | yes | Flow Stack definition |
| `classification` | object | yes | Classification results |
| `resolved_invocations` | array | yes | Resolved invocations |
| `runtime_guidance` | array | yes | Runtime guidance |
| `warnings` | array | yes | Warning list (unused slots, etc.) |

### `flow_stack.slots[]`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `slot_id` | string | yes | `snake_case` slot identifier |
| `slot_type` | `"layerable"` \| `"exclusive"` | yes | Slot type |
| `activation` | `"always"` \| `"conditional"` \| `"on_demand"` \| `"gate"` | yes | Activation condition |
| `default` | object | no | Default assignment |
| `default.skill` | string | no | Default skill name |
| `default.reason` | string | no | Rationale for the default assignment |

### `classification.categories[]`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | yes | Category identifier |
| `label` | string | yes | Display name |
| `skills` | string[] | yes | Member skill names |

### `resolved_invocations[]`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `source_skill` | string | yes | Invoking skill |
| `slot` | string | no | Target slot |
| `capability` | string | yes | Target capability |
| `resolved_skill` | string | yes | Resolved skill |
| `resolution_method` | string | yes | Resolution method (slot_override/capability_override/default_skill/provider_lookup) |
| `reason` | string | no | Resolution rationale |
| `fallback` | string \| null | no | Fallback target |

### `runtime_guidance[]`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `skill` | string | yes | Target skill name |
| `context` | string | yes | Applicable context |
| `guidance` | string | yes | Guidance text |
| `priority_delta` | number | no | Explicit priority adjustment |
| `prefer_when` | string[] | no | Context keywords to prefer |
| `avoid_when` | string[] | no | Context keywords to avoid |
| `requires_sequence` | boolean | no | Whether the guidance requires ordering constraints |
| `requires_step_reordering` | boolean | no | Whether step reordering is required |
| `requires_partial_application` | boolean | no | Whether partial application is required |

`runtime_guidance` is structured metadata; a flow consults it after checking
`execution_policy`. When `runtime_guidance` is empty, the profile operates
deterministically using only `resolved_invocations` and `execution_policy`.

## Sort Rules

- `resolved_invocations[]`: lexicographic order by `source_skill` → `slot` →
  `capability`
- `classification.categories[]`: lexicographic order by `id`
- `flow_stack.slots[]`: preserves adapter YAML declaration order

## Relationship to the Skill Reference Catalog

- The Flow Profile references the Catalog and adds flow-specific resolution
  results
- `resolved_invocations` is generated from the adapter's
  `invocation_resolution` settings
- The Catalog has no `resolved_skill` (it carries `default_skill` only)
