# 根本原因トレーシング

コールスタックを逆方向にトレースしてバグの元のトリガーを見つける。

## テクニック

コード深くで不正な値を見つけても、そこで修正しない。逆方向にトレースする:

```
不正な値はどこに現れるか？
    ↓
この関数を不正な値で呼んだのは何か？
    ↓
呼び出し元はその値をどこから得たか？
    ↓
何がその値を不正に設定したか？
    ↓
（ソースが見つかるまで続ける）
```

## キールール

- **症状箇所で修正しない** — 症状は問題に気づいた場所に過ぎない
- **トレースを続ける** — ソースが見つかっていなければ根本原因は見つかっていない
- **一段ずつ** — コールスタックのレベルを飛ばさない
- **トレースを文書化する** — 各ホップを書き留めて迷わないようにする
- **ソースで一度だけ修正する** — ソース修正がすべての下流症状を防ぐ
