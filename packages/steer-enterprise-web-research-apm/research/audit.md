- [ ] All must-cover aspects have evidence.

## Evidence

- [ ] Important factual claims have sources.
- [ ] Current/changing facts are supported by recent or official sources.

## Contradictions

- [ ] Contradictory evidence has been checked.
- [ ] Source quality explains which claim is more credible.

## Search Quality

- [ ] Official/primary-source search attempted.
- [ ] Critical/negative search attempted.
- [ ] Duplicate sources removed.
- [ ] At least one follow-up search performed for high-priority gaps.

- [ ] Persona/intent model reflects user constraints.
- [ ] Pause decisions were used only for high-impact ambiguity.
