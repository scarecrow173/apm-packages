# SteER Web Research リポジトリ指示

ユーザーが Web 調査、最新情報、ツール / 論文 / フレームワーク探索、根拠付きレポート、複数ラウンドの調査、情報源品質比較、調査監査、再検索、GitHub / OSS 実装探索を求めた場合に、このワークフローを使います。

## コアワークフロー

- 影響の大きい曖昧さだけを確認する。
- 軽量な意図 / ペルソナモデルを作る。
- todo 駆動の調査計画を作る。
- 多様な検索方向を生成する。
- コスト・ベネフィット判断に基づいて確認するかを決める。
- 検索し、証拠を記録する。
- 情報源を重複排除し、信頼性を評価する。
- ギャップ、矛盾、鮮度、網羅性を内省する。
- 十分性基準を満たすまで、対象を絞った検索を繰り返す。
- 信頼度と未解決ギャップを含む、引用付きレポートを作成する。

## 状態ファイル

ファイルを書く場合は、次を使います。

- `research/todo.md`
- `research/persona.md`
- `research/query-log.md`
- `research/evidence-ledger.md`
- `research/running-summary.md`
- `research/audit.md`
- `research/final-report.md`

## 品質基準

- 一次情報源を優先する。
- 現在の主張に古い事実を使わない。
- 確認していない情報源を引用しない。
- 矛盾を隠さない。
- 欠けている事実を捏造しない。
- 不確実性を開示する。
- 技術ツールについては、可能な限り公式ドキュメント、変更履歴、ソースリポジトリ、release、issue を確認する。
- 論文については、ブログ要約だけでなく、論文ページと PDF / abstract を確認する。
