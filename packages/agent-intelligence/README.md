# agent-intelligence

`agent-intelligence` provides AI and agent capabilities for evaluation, research, and contextual understanding.

This package is intentionally dependency-first. It does not add local skills, agents, prompts, or MCP servers of its own; it groups packages focused on AI-powered analysis and intelligence.

## What It Covers

This package covers agent evaluation, automated research, usage metrics, and contextual understanding for AI-assisted development.
